# BASE — Умная аренда

**Финансовая свобода начинается с правильного выбора.**

BASE отвечает на один вопрос: *как жить комфортно, безопасно и экономно, не платя за жильё, которым вы не пользуетесь?* Приложение сравнивает посуточную, понедельную и долгосрочную аренду (через риелтора, напрямую, апарт-отель, свой вариант) при вашем реальном графике — с дежурствами в Краматорске на 7–14 дней в месяц.

- Работает в браузере на iPhone, Android и компьютере, устанавливается на главный экран (PWA).
- После первого открытия работает **без интернета**.
- Без регистрации, без сервера, без платных API. Данные хранятся только на вашем устройстве.
- Все стартовые суммы — **иллюстративные**, а не рыночные предложения. Замените их своими.

## Что внутри

Все 15 файлов лежат в одной папке — без подпапок, чтобы GitHub принял их одной загрузкой с iPhone.

```
index.html              — оболочка приложения
styles.css              — дизайн: тёмная графитовая и светлая темы, безопасные области iPhone
finance.js              — единый вычислительный модуль: все числа приложения берутся только отсюда
charts.js               — собственные графики на SVG (без библиотек)
app.js                  — интерфейс: экраны, листы настроек, экспорт/импорт
manifest.webmanifest    — описание PWA
service-worker.js       — офлайн-режим
icon-180.png            — иконка для iPhone
icon-192.png, icon-512.png, icon-maskable-512.png — иконки для Android и браузеров
finance.test.js         — 44 проверки формул (Node и браузер)
tests.html              — запуск проверок в браузере
README.md               — эта инструкция
```

Внешних зависимостей нет: ни библиотек, ни шрифтов, ни CDN. Поэтому приложение не сломается из‑за чужого сервера и полностью работает офлайн.

## Разделы

| Раздел | Что делает |
|---|---|
| **Главная** | Лучшая стратегия и экономия в месяц против выбранной базы, стоимость месяца, экономия за год, деньги для заселения, оплаченные пустые дни, гибкость и комфорт. Быстрые пресеты: 7 / 10 / 14 дней, цена ночи, горизонт. Советник, денежный поток, калькулятор свободы. |
| **Сравнение** | Карточки шести вариантов с настройками, таблица (экспорт CSV), альтернативная стоимость залога, четыре графика, раздел «Города» (Днепр, Каменское, свой город). |
| **Сценарии** | «Что, если?»: 7/10/14 дней, рост аренды, снижение посуточной цены, квартира без риелтора, недельная скидка, рост коммунальных. Показывает, что сильнее всего влияет на годовой бюджет; сценарий можно применить и отменить. |
| **Мои варианты** | Реальные объявления с Booking, OLX и др.: цены вводятся вручную (и помечены как непроверенные), удобства, заметки. Сравнение до пяти объектов, перенос объекта в общее сравнение. |
| **Настройки** | Тема, анимации, календарный или условный месяц, проживающие, ставка вклада, цель резерва, экспорт/импорт, проверка формул. |

### Три функции, ради которых хочется возвращаться

1. **Денежный поток** — лента платежей по месяцам: что заплатить, что заморожено в залоге, что вернётся и когда. Видно разницу между «деньги уходят сейчас» и «это расход».
2. **Момент безубыточности** — цена ночи, выше которой выгоднее постоянная аренда, и месяц, когда долгосрочный вариант окупает комиссию. Показывает запас прочности до порога.
3. **Freedom Score** — прозрачная оценка финансовой гибкости: четыре фактора по 25% (предоплата сверх месяца, невозвратные платежи, срок обязательств, оплата пустых дней) с объяснением каждого балла.

Плюс **калькулятор свободы**: сколько экономия даст за 1/3/6/12 месяцев, сколько это месяцев жизни, когда наберётся резерв и как его копить. Доходность — ваша ставка, не обещание.

## Как считается

- **Расход** — деньги, которые не вернутся: аренда, коммунальные, комиссия, уборка, сборы, удержанная часть залога.
- **Возвратный залог** не входит в расходы — это замороженные деньги. Отдельно показана их альтернативная стоимость (упущенный доход по вашей ставке, простые проценты).
- **Комиссия риелтора** и оформление — расход первого месяца.
- **Предоплата последнего месяца** меняет только график платежей, расходы не меняются (не учитывается дважды).
- **Скидки** не складываются: Genius и скидка за длительность применяются последовательно (10% и 15% = −23,5%), из скидок за 7/14/28 ночей действует одна — самая выгодная для длины брони. Можно выбрать режим «только наибольшая».
- **Ночей дома** = дней в месяце − дней дежурства − других дней вне дома. В календарном режиме учитываются 28/29/30/31 день.
- **«Вы экономите … в месяц»** = средний месяц базы − средний месяц лучшего варианта на выбранном горизонте.

Проверки из ТЗ (все проходят):

| Тест | Ожидается | Результат |
|---|---|---|
| А. 20 ночей × 700 ₴ | 14 000 ₴/мес, 168 000 ₴/год | ✓ |
| Б. Риелтор 18 000 + 3 000, комиссия 18 000 | 39 000 первый месяц, 144 000 за 6, 270 000 за 12 | ✓ |
| В. Напрямую 15 000 + 3 000 | 18 000 ₴/мес, 216 000 ₴/год | ✓ |
| Г. Экономия посуточно против риелтора | 102 000 ₴/год | ✓ |
| Д. 16 ночей | 11 200 ₴/мес, 134 400 ₴/год | ✓ |
| Е. 23 ночи | 16 100 ₴/мес, 193 200 ₴/год | ✓ |

Также проверены нули, отрицательные и пустые поля, скидки 100% и выше 100%, дежурство дольше месяца, частичная потеря залога, предоплата последнего месяца, несколько броней, февраль и месяцы по 31 дню, отсутствие двойного учёта скидок. Запуск: `node finance.test.js` или «Настройки → Проверка формул».

## Установка на GitHub Pages

### 1. Распаковать архив
Откройте `BASE_GITHUB.zip` в приложении «Файлы» (одно касание) — появится папка `BASE_GITHUB` с 15 файлами. Подпапок нет.

### 2. Создать репозиторий
1. Войдите на [github.com](https://github.com) (или зарегистрируйтесь — это бесплатно).
2. Нажмите **«+» → New repository**.
3. Название, например `base`. Видимость — **Public** (для бесплатного GitHub Pages).
4. Нажмите **Create repository**.

### 3. Загрузить файлы
1. В Safari на странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**). Если кнопки нет — включите версию для ПК: **аА → Запрос настольного веб-сайта**.
2. Нажмите **choose your files** → **Обзор** → откройте папку `BASE_GITHUB`.
3. Нажмите **«Выбрать»** (вверху справа), отметьте **все 15 файлов** → **Открыть**.
4. Дождитесь, пока все файлы появятся в списке, и нажмите **Commit changes**.

Главное — чтобы `index.html` лежал прямо в корне репозитория, а не внутри папки.

### 4. Включить GitHub Pages
1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Ветка **main**, папка **/(root)**, нажмите **Save**.
4. Через 1–2 минуты появится адрес вида `https://ВАШ-ЛОГИН.github.io/base/`.

Все пути в приложении относительные, поэтому оно работает и в подпапке репозитория.

### 5. Открыть на iPhone
Откройте адрес из шага 4 в **Safari**. Первое открытие нужно с интернетом — после него BASE сохраняет себя для офлайн-работы.

### 6. Добавить на главный экран
1. В Safari нажмите **«Поделиться»** (квадрат со стрелкой вверх).
2. Выберите **«На экран „Домой“»** → **«Добавить»**.
3. Запускайте BASE с иконки: он откроется на весь экран, без панелей браузера, и будет работать без сети.

На Android: Chrome → меню **⋮** → **«Установить приложение»**.

### 7. Экспорт и восстановление данных
Данные хранятся в памяти браузера на конкретном устройстве. Чтобы не потерять их при смене телефона или очистке Safari:

- **Сохранить:** Настройки → **Экспорт JSON**. На iPhone откроется меню «Поделиться» — выберите **«Сохранить в Файлы»** или отправьте себе в мессенджер. Кнопка **«Скопировать»** кладёт те же данные в буфер обмена (можно вставить в заметку).
- **Восстановить:** Настройки → **Импорт** → выберите файл или вставьте скопированный текст → **Импортировать**. Если передумали — нажмите **«Отменить»** во всплывающем сообщении.
- **Таблица сравнения:** Сравнение → Таблица → **Экспорт CSV** (открывается в Excel, Numbers, Google Таблицах).

> Важно: приложение на главном экране iPhone и сайт в Safari хранят данные **раздельно**. Если начали в Safari, а потом установили на экран «Домой», перенесите данные через Экспорт/Импорт.

## Обновление
Чтобы выпустить новую версию, загрузите изменённые файлы в репозиторий (одноимённые файлы заменятся) и увеличьте `VERSION` в `service-worker.js` (например, `base-v1.0.2`). При следующем запуске BASE предложит «Обновить».

## Конфиденциальность
BASE ничего не отправляет на серверы и не собирает данные. Ссылки на объявления открываются во внешнем браузере; цены с Booking или OLX не загружаются автоматически — их вводите вы сами.

## Важно
BASE — калькулятор, а не финансовая или юридическая консультация. Перед подписанием договора проверьте условия, залог и порядок его возврата у собственника или риелтора.
